# Compare scenarios with a stacked variance chart

## What the chart shows

Each scenario appears as one stacked column. Its segments show values for a segment dimension when one is configured, and a total marker shows the net total. A bridge connects the total markers for each comparison. The callout gives the signed variance in value and percent, based on the reference scenario.

Use this chart to compare how a metric's total and segment mix change across plans, periods, or alternatives. It is useful when scenarios represent comparable options and share the same segment definition.

## Set up the chart

In the property panel, choose scenarios as measures or as values from a dimension. Add a segment dimension when needed. Set comparison pairs directly or use a preset. Choose how to label segments and callouts, and adjust the legend, total labels, tooltip, segment limit, and increase direction. The tooltip can include up to three expression rows.

## Selections

Select a segment to update selections in the Qlik app. In dimension mode, an author can also allow scenario selection. The chart marks selected segments so you can see the selection state.

## Keyboard use

Tab to the chart. Use the arrow keys to move between segments and comparison callouts. Press Enter or Space to select a focused segment. Press Escape from an open tooltip to return to its mark. The accessible data table provides the chart values and comparisons in text form.
